# Самая длинная серия

Есть список дней: занимался ты в этот день или нет. Напиши функцию `longestStreak(days)`, которая вернёт самую длинную серию дней подряд, когда ты занимался.

```js
longestStreak([true, true, false, true, true, true]) // 3
longestStreak([])                                     // 0
```

Запуск тестов: `node --test`

Застрял — напиши ИИшке «застрял» и получишь первую подсказку, а не готовый код.
