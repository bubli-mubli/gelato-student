# Частые слова

Напиши функцию `top_words(text, n)`: верни `n` самых частых слов текста в виде списка пар `(слово, сколько раз)`, от частых к редким. Регистр не важен, знаки препинания не считаются словами.

```python
top_words("Кот и пёс. Кот!", 1)  # [("кот", 2)]
```

Запуск тестов: `python3 -m unittest`
