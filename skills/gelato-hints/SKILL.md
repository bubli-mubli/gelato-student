# gelato-hints — лестница подсказок

Ведёт к решению ступеньками: каждая следующая — конкретнее предыдущей. Готовый код — только на последней и только по прямой просьбе.

## Когда

- «застрял», «не получается», «не знаю, как дальше», «с чего начать?»
- «подскажи», «намекни», «дай подсказку»
- «подскажи ещё», «всё ещё не понимаю» — следующая ступень

Есть текст ошибки или стектрейс — это `gelato-debug`.

## Нельзя

- Готовое решение на ступенях 1–3, даже по кусочкам, которые в сумме дают решение.
- Перескакивать ступени: один ответ — одна ступень. Следующая — после попытки ученика или его просьбы.
- Ступень 4 без явной просьбы («покажи решение», «дай готовый код», «сдаюсь»). «Подскажи побольше» — это следующая ступень, а не решение.
- Править файлы ученика.
- Больше одного вопроса в ответе.

## Ступени

1. **Направление.** Какую идею применить, какой вопрос задать себе. Без кода. Хорошо работает аналогия из жизни: «как ты считал бы это на бумажке?».
2. **План.** Шаги словами, нужная конструкция языка или функция стандартной библиотеки, место в файле, куда писать.
3. **Фрагмент.** 1–3 строки ключевого места с пропусками `___` или псевдокод. Не весь код.
4. **Решение.** Сначала одна фраза о цене: «Готовый код закроет задачу, но навык не появится — потом попробуй написать это сам без подсказок». Затем минимальный код для текущего шага, в стиле кода ученика. После — попроси объяснить своими словами ключевую строку.

## Процесс

1. Определи стек и как запускать тесты (файлы проекта, README).
2. Найди задачу (README, `TODO`, текст ученика) и его код. Задача непонятна — один уточняющий вопрос и стоп.
3. Найди место затыка: что уже написано и какой следующий шаг не выходит. Подсказка — про этот шаг, не про всю задачу.
4. Ступень: первая просьба по задаче — 1, повторная после попытки — следующая, явная просьба решения — 4.
5. Дай подсказку и остановись: последней строкой — действие для ученика.
6. Пришла попытка — запусти код или тесты. Работает — заверши. Нет — скажи, что уже сдвинулось, и одну вещь, которая мешает; следующая ступень — только если ученик снова застрял.

## Формат

```
**Подсказка N из 4 — <направление | план | фрагмент | решение>**

<2–8 строк>

Попробуй: <одна строка>
```

## Завершение

- Код работает — подтверди результатом запуска и задай один вопрос: почему этот приём работает или что сломается без него.
- Отметь задачу в дневнике (`gelato-progress`): название, до какой ступени дошли. Ступень 4 — так и запиши, без осуждения.
- Новая задача начинается со ступени 1.
