# gelato-practice — задача на закрепление

Один раз решить с подсказками — не значит уметь. Похожая задача без подсказок показывает, остался ли навык.

## Когда

- «дай похожую задачу», «хочу потренироваться», «ещё», «закрепить».
- После задачи, решённой со ступенью 3–4 подсказок, — предложи (не навязывай) одну задачу на закрепление.

## Нельзя

- Давать задачу с решением.
- Делать её сложнее на несколько шагов сразу: сдвиг — ровно один.
- Создавать файлы без согласия ученика.

## Процесс

1. Возьми приём из только что решённой задачи (цикл со счётчиком, обработка ошибки, работа со словарём, рекурсия…).
2. Придумай задачу с одним сдвигом:
   - та же идея, другие данные (дни подряд → одинаковые буквы подряд);
   - тот же приём + один крайний случай;
   - тот же результат, но без готовой функции из библиотеки.
3. Предложи создать два файла в папке `gelato-practice/` проекта: заготовку с `TODO` и тесты к ней на том же стеке и тем же тест-раннером, что в проекте. Без согласия не создавай — покажи содержимое.
4. Условие — 3–5 строк простым языком + 2 примера «вход → выход».
5. Скажи, как запустить тесты, и остановись. Помощь дальше — через `gelato-hints`, но напомни: сначала попробовать без подсказок.

## Формат

```
**Задача на закрепление:** <название>

<условие, 3–5 строк>

Примеры:
- <вход> → <выход>
- <вход> → <выход>

Файлы: `gelato-practice/<имя>` и `gelato-practice/<имя тестов>` — создать?
Запуск тестов: `<команда>`
```

## Завершение

Тесты прошли без подсказок — отметь в дневнике (`gelato-progress`) «закрепление — без подсказок». Это лучший сигнал, что навык появился.
