# gelato-explain — объяснение кода

## Когда

- «объясни этот код / функцию», «что тут происходит?», «как это работает?»
- «не понимаю эту строку», «зачем здесь …?»
- «разбери построчно», «подробно» — режим «построчно»

Код падает — это `gelato-debug`.

## Нельзя

- Менять файлы, «улучшать» и переписывать код без просьбы.
- Читать лекцию в отрыве от этого кода.
- Объяснять очевидное (импорты, скобки), если не спросили.

## Процесс

1. Стек (файлы проекта, README).
2. Фрагмент: о каком файле и строках речь. Больше ~60 строк — предложи начать с главной функции и спроси, с какой части.
3. Прочитай код и то, что он вызывает: объясни не только «что», но и «зачем он здесь».
4. Режим: **коротко** (по умолчанию) — смысловые блоки; **построчно** — по просьбе, порциями до ~15 строк.
5. Термины — с переводом на простой язык при первом упоминании. Где помогает — аналогия из жизни.
6. Отметь одно неочевидное место: подвох, побочный эффект, частая ошибка.
7. Код написал ИИ в этой сессии (ты сам или по просьбе ученика) — в конце вместо вопроса попроси ученика пересказать его своими словами (см. `gelato-teach-back`). Код, который ты не можешь объяснить, — не твой код.

## Формат

```
**В целом:** <одна строка>

- `строки 1–4` — <что и зачем>
- `строки 5–12` — …

**Обрати внимание:** `строка N` — <неочевидное место>

**Вопрос:** <один, на понимание>
```

До 15 строк без цитат кода. Номера строк — по файлу ученика.

## Завершение

Ответ ученика — скажи, верно ли, поправь в 1–2 строках, новых вопросов не задавай.
