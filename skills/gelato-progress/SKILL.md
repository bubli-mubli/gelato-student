# gelato-progress — дневник учёбы

Учёба с ИИшкой незаметно превращается в «ИИшка сделала, я нажал Enter». Дневник делает это видимым: сколько задач решено самим, а сколько — готовым кодом.

## Файл

`.gelato/journal.md` в корне проекта. Нет — создай при первой записи (это единственный файл, который ты меняешь без отдельной просьбы). Предложи ученику добавить `.gelato/` в `.gitignore`, если он не хочет хранить дневник в репозитории.

Запись о задаче — одна строка таблицы:

```
| дата | задача | навык | подсказки | объяснил сам | закрепление |
|---|---|---|---|---|---|
| 2026-10-25 | longestStreak | цикл со счётчиком | 2 из 4 | да | без подсказок |
```

- **задача** — короткое имя (функция, файл, тема);
- **навык** — приём простыми словами: «цикл со счётчиком», «чтение ошибки», «работа со словарём»;
- **подсказки** — до какой ступени `gelato-hints` дошли: «сам», «1 из 4» … «4 из 4 — готовый код»; для ошибок — «разобрал ошибку сам / с подсказкой»;
- **объяснил сам** — прошёл ли `gelato-teach-back`: да / частично / нет;
- **закрепление** — результат `gelato-practice`, если был.

## Когда писать

- Задача закрыта (тесты прошли) — одна строка, без вопросов ученику; всё, что неизвестно, — «—».
- Ученик просит отчёт — отчёт (ниже).

## Отчёт «мой прогресс»

1. Прочитай дневник целиком.
2. Посчитай: задач всего; решено сам или на ступенях 1–2; дошло до ступени 4; объяснил сам.
3. Найди сигналы:
   - **плохой знак** — 3 последние задачи подряд дошли до ступени 4, или больше половины задач без «объяснил сам». Скажи прямо и мягко: «ты привыкаешь брать готовое — следующую задачу попробуй до первой подсказки 15 минут сам»;
   - **уже навык** — один и тот же навык 3 раза и больше «сам» или «без подсказок». Скажи: «это ты уже умеешь — такую рутину можно спокойно отдавать ИИшке целиком»;
   - **пробел** — навык, на котором чаще всего нужна ступень 3–4. Предложи `gelato-practice` именно на него.
4. Формат — до 12 строк:

```
**Задач:** N · сам или с лёгкой подсказкой: N · с готовым кодом: N · объяснил сам: N

**Уже умеешь:** <навыки>
**Проседает:** <навык> — <предложение gelato-practice>
**Сигнал:** <плохой знак / всё хорошо — одной фразой>
```

## Нельзя

- Приукрашивать: дневник честный, иначе он бесполезен.
- Стыдить: готовый код — нормальный шаг, если потом объяснил и закрепил.
